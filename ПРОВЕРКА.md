# Проверка обновления от 11 ноября 2026

Локальный код до изменений совпадал с GitHub. Отличалась только `ИНСТРУКЦИЯ.md`;
её актуальная версия с GitHub перенесена в эту ветку.

## Что изменилось

- Процентная шкала справа использует тот же диапазон и шаг, что и количество
  бросков слева. Например, 15 из 80 бросков соответствует 18,8%.
- В полях количества выпадений стрелки ← и → переходят к соседней сумме.
  При переходе или щелчке число выделяется целиком, поэтому его можно сразу заменить.
- Tab и Shift+Tab также позволяют переходить между полями с выделением числа.

## Локальный предпросмотр

Открой http://127.0.0.1:5050 после запуска из папки проекта:

```powershell
python tools/preview.py
```

Дополнительные библиотеки для предпросмотра не нужны. Игры в этом режиме
хранятся в `.local/preview-games.json`, отдельно от Supabase. Вверху страницы
есть жёлтая плашка. Пробная игра «Пример — локальная проверка» содержит 80 бросков.

Параметр `--load-live` может прочитать историю с Render при первом запуске,
когда локального файла ещё нет. При подготовке этой версии запрос к
`https://catan-tracker.onrender.com/api/games` вернул HTTP 500, поэтому история
семейных игр в предпросмотр не загружена.

Обычный запуск `python app.py` по-прежнему работает с Supabase через `.env`.
Рабочий сайт Render не обновлялся; на GitHub изменения не отправлялись.

## Быстрый откат

Исходная локальная версия: Git-метка `backup/before-input-and-percent-2026-11-11`
и архив `backups/catan-before-2026-11-11.zip`.
Текущая версия GitHub до правок: метка `backup/render-before-2026-11-11`.
Архив не содержит `.env`; существующие настройки подключения остаются в папке проекта.

Чтобы вернуть исходный интерфейс, сохрани нужные новые изменения и выполни:

```powershell
git restore --source=backup/render-before-2026-11-11 -- templates/index.html
```

Либо скопируй `templates/index.html` из резервного ZIP поверх нового файла.
Это меняет только интерфейс. Данные семейных игр в Supabase сохранятся.
