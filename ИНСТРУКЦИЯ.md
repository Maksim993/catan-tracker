# 🎲 Катан — Статистика кубиков
## Инструкция по запуску

---

## ШАГ 1 — Создай базу данных в Supabase (бесплатно, 5 мин)

1. Зайди на https://supabase.com и нажми **Start your project** → войди через GitHub или почту
2. Нажми **New project**, придумай название (например `catan`) и пароль — сохрани куда-нибудь
3. Подожди ~1 минуту пока проект создаётся
4. В левом меню нажми **SQL Editor** → нажми **New query**
5. Вставь и выполни (кнопка Run ▶) этот SQL:

```sql
create table games (
  id         bigint generated always as identity primary key,
  created_at timestamptz default now(),
  winner     text not null,
  date       text not null,
  players    int  default 4,
  total      int  default 0,
  r2  int default 0, r3  int default 0, r4  int default 0,
  r5  int default 0, r6  int default 0, r7  int default 0,
  r8  int default 0, r9  int default 0, r10 int default 0,
  r11 int default 0, r12 int default 0
);
```

6. В левом меню нажми **Project Settings** → **API**
7. Скопируй:
   - **Project URL** (выглядит как `https://abcdefgh.supabase.co`)
   - **anon / public** ключ (длинная строка начинающаяся с `eyJ...`)

---

## ШАГ 2 — Настрой файл `.env`

Открой файл `.env` в папке проекта и вставь свои данные:

```
SUPABASE_URL=https://ТВОЙ_ID.supabase.co
SUPABASE_KEY=eyJhbGci...ТВОЙ_КЛЮЧ
```

---

## ШАГ 3 — Установи Python-зависимости

Открой **Терминал** (или Командную строку) в папке с проектом и выполни:

```bash
pip install -r requirements.txt
```

Если Python не установлен — скачай с https://python.org (версия 3.10+)

---

## ШАГ 4 — Запусти сервер

```bash
python app.py
```

Ты увидишь что-то вроде:
```
* Running on http://0.0.0.0:5000
```

---

## ШАГ 5 — Открой сайт

- **На своём компьютере:** http://localhost:5000
- **С телефона / другого устройства в той же Wi-Fi сети:**  
  Узнай IP своего компьютера (Windows: `ipconfig`, Mac/Linux: `ifconfig`)  
  и открой: `http://192.168.X.X:5000`

## Как пользоваться

**➕ Новая игра**
- Введи количество выпадений каждого числа (2–12)
- Укажи победителя, количество игроков и дату
- Нажми «Сохранить игру»

**🎮 Игры**
- Список всех игр, кликни на любую — увидишь её график
- Кнопка ✕ удаляет игру

**📊 Статистика**
- Суммарный график всех бросков с линией теории
- График отклонений от теоретических вероятностей

**🏆 Победители**
- Карточки игроков с количеством побед и медалями

## ДЕПЛОЙ — Выложить сайт в интернет (Railway, бесплатно)

Чтобы сайт был доступен по постоянной ссылке **без запущенного компьютера**:

### Подготовка: залить код на GitHub

1. Зайди на https://github.com и создай аккаунт (если нет)
2. Нажми **New repository** → назови `catan-tracker` → **Create repository**
3. В папке проекта выполни в терминале:

```bash
git init
echo ".env" >> .gitignore
git add .
git commit -m "first commit"
git remote add origin https://github.com/ТВО_ИМЯ/catan-tracker.git
git push -u origin main
```

> ⚠️ Файл `.env` добавлен в `.gitignore` — ключи Supabase **не попадут** в GitHub

### Деплой на Railway

1. Зайди на https://railway.app и войди через GitHub
2. Нажми **New Project** → **Deploy from GitHub repo** → выбери `catan-tracker`
3. Railway сам обнаружит Python-проект и запустит сборку (~2 мин)
4. Зайди в проект → вкладка **Variables** → добавь две переменные:
   - `SUPABASE_URL` = твой URL из Supabase
   - `SUPABASE_KEY` = твой ключ из Supabase
5. Зайди в **Settings** → **Networking** → **Generate Domain**
6. Получишь ссылку вида `https://catan-tracker-production.up.railway.app` — её можно кидать всем!

### Обновление сайта в будущем

Если захочешь изменить что-то в коде — просто сделай `git push`, Railway автоматически обновит сайт.

## Структура файлов

```
catan/
├── app.py              ← сервер (Flask)
├── Procfile            ← команда запуска для Railway
├── railway.json        ← настройки Railway
├── .gitignore          ← исключает .env из Git
├── .env                ← твои ключи Supabase (не показывай никому!)
├── requirements.txt    ← зависимости Python
└── templates/
    └── index.html      ← сам сайт
```
